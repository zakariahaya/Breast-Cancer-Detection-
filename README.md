# Breast-Cancer-Detection-
Malignant vs. benign tumor classification with SVMs
Classifies breast tumors as Malignant or Benign using Support Vector Machines, comparing a linear kernel against a tuned RBF kernel on the Wisconsin Diagnostic Breast Cancer dataset.

Dataset
Source: Kaggle — Breast Cancer Wisconsin (Diagnostic) Data Set
569 samples, 30 numeric features computed from digitized images of fine needle aspirate (FNA) biopsies (e.g. radius, texture, perimeter, area, smoothness — each reported as mean, standard error, and "worst" value)
